# Simulacion Computadora

Este repositorio contiene las practicas realizadas con godot en la materia de Simulacion por Computadora

## squash the creeps start
En esta práctica se creó una escena 3D en Godot y se añadió un personaje que puede desplazarse utilizando las teclas de dirección del teclado.

### Objetivo
- Familiarizarse con el entorno de Godot.
- Comprender la estructura básica de una escena 3D.
- Implementar el movimiento del personaje mediante entrada del teclado.

## Creacion de escenario 3d con personaje desplazable

En esta practica se utiliza un escenario 3D realizado anteriormente en blender inspirado en Crossy Road y se añadio un personaje que puede desplazarse utilizando las teclas de dirección del teclado.

### Objetivos
- Aprender la estructura de un proyecto en Godot.
- Comprender el uso de nodos.
- Practicar la programación con GDScript.
